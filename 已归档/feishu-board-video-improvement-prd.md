# 飞书文档画板视频分析与 CloudDoc 改进 PRD

版本：V1.0
日期：2026-04-22
状态：已实现首版
来源视频：`/Volumes/ForBackUp/飞书文档-画板-演示视频.mp4`
范围：基于视频修正当前 CloudDoc 独立基础画板的样式和功能点

## 1. 背景

CloudDoc 已完成独立基础画板首版，具备 `document_type = board`、新建入口、基础图形、连接线、平移、缩放、保存和只读权限控制。

用户提供了一个飞书文档画板的简单使用视频。该视频展示的重点不是复杂协作，而是基础画板的工作台布局、左侧工具栏、图形库、对象选中态、浮动工具条、连接线样式、文本编辑和颜色设置。当前 CloudDoc 已具备基础数据闭环，但在交互细节和视觉风格上仍明显不像飞书画板。

本 PRD 用于指导下一轮实现：先对齐视频中可见的基础能力和样式，不扩大到多人协作、文档内嵌画板、AI 生成、导出等更大范围。

## 2. 视频观察摘要

视频时长约 117.7 秒，分辨率约 1898 x 744。关键观察点：

- 0-8 秒：页面顶部左侧有返回、父级文档标题“画板文档”、当前画板 Tab“画板”；右上角有分享、编辑模式、搜索、评论/更多入口。
- 0-16 秒：左侧是固定垂直工具栏，白色窄条，图标从上到下排列，包含选择/形状/文本/便签或注释/连接线/容器或框架/表格/画笔/更多/评论等。
- 7 秒左右：点击形状工具后出现紧凑图形面板，面板包含矩形、圆形、菱形、圆角矩形、数据库、箭头、星形、括号等图形，并有“更多图形”入口。
- 0-30 秒：画布是浅色无限画布，背景为细点阵，不是强网格线；画布中心留白大，图形呈浅蓝填充、蓝色选中描边。
- 0-40 秒：选中图形后，在对象下方或附近出现浮动工具条，而不是右侧常驻面板。工具条包含形状、填充、边框/线条、文字颜色、字号、文本样式、评论、更多。
- 40-60 秒：连接线从对象边缘锚点拉出，吸附到另一个对象；连接线可以是直线或折线，终点箭头可调整。选中连接线时浮动工具条切换为线条相关设置。
- 48-56 秒：连接线样式菜单支持不同箭头形态、线宽或端点样式，菜单紧凑，下拉项用图形预览表达。
- 56-70 秒：右键或更多菜单显示复制、剪切、粘贴、创建副本、删除、上移/下移、更多等对象操作。
- 80-96 秒：选中对象后可打开形状库/快捷图形面板，从当前对象附近直接继续添加其他形状。
- 88-96 秒：颜色菜单为紧凑浮层，包含文字颜色/背景色、色板矩阵，当前色有选中态。
- 96-117 秒：文本编辑直接在图形内部进行，多行文本在图形内自动换行，图形可随文本内容扩展或至少完整显示文本。

## 3. 飞书画板样式规则

### 3.1 页面整体

- 画板页应接近全屏工具台，不应显示文档阅读页的大标题排版。
- 顶部栏高度约 40px 到 48px，信息密度高。
- 顶部左侧显示来源文档/画板路径和当前画板标题，右侧显示分享、编辑模式、搜索、评论、更多。
- 画布区域占满剩余窗口，内容靠左上工作区展开，不需要文档页面式左右大留白。

### 3.2 画布背景

- 使用浅灰点阵背景，点阵间距约 20px 到 24px。
- 背景不要使用明显网格线，避免像工程 CAD 网格。
- 画布应能无限扩展或至少在大区域内平移。

### 3.3 左侧工具栏

- 固定在画布左侧，宽度约 40px 到 48px。
- 工具栏为白色半透明或纯白窄条，有轻边框。
- 图标优先，不显示文字；鼠标悬浮显示 tooltip。
- 激活工具用轻蓝或浅灰底突出。
- 工具组之间用细分割线分隔。

### 3.4 图形和选中态

- 默认图形使用浅蓝填充，蓝色边框；圆角矩形圆角较小。
- 未选中对象边框轻，选中后显示蓝色描边、角点/边点控制柄、锚点。
- 图形文本居中，字号默认约 14px。
- 多行文本需在图形内换行显示。

### 3.5 浮动工具条

- 对象选中后显示就地浮动工具条，优先显示在对象下方；空间不足时自动翻转到上方或侧边。
- 工具条不占用画布布局空间，是绝对定位浮层。
- 工具条为白底、轻边框、轻阴影，按钮高度约 28px 到 32px。
- 工具条内容随选中对象类型变化：形状对象显示形状/填充/边框/文字/评论/更多；连接线显示线型/箭头/颜色/文字/更多。
- 点击画布空白处工具条消失。

### 3.6 下拉菜单

- 图形库、颜色、线条、更多菜单都应是紧凑浮层。
- 图形库使用网格图标，不用长文本列表。
- 颜色面板包含最近颜色、常用色板、文字/填充/边框区分。
- 更多菜单使用文本列表，支持快捷键提示。

## 4. 飞书画板功能点拆解

### 4.1 必须对齐的视频内功能

- 左侧垂直图标工具栏。
- 图形工具点击后展开图形库面板。
- 支持矩形、圆角矩形、圆形、菱形、基础箭头、数据库/圆柱、星形等常见图形。
- 使用图形工具后，在画布点击创建对象。
- 支持对象选中、拖拽移动、调整大小。
- 支持对象锚点，连接线从锚点吸附到另一个对象。
- 支持直线和折线连接线。
- 支持连接线箭头方向和端点样式。
- 支持对象内直接编辑文本。
- 支持多行文本自动换行。
- 支持填充色、边框色、文字颜色、字号调整。
- 支持对象右键菜单或更多菜单：复制、剪切、粘贴、创建副本、删除、层级移动。
- 支持撤销、重做。
- 支持画布缩放和平移。
- 支持自动保存。

### 4.2 当前可暂缓功能

- 多人协作光标。
- 画板对象评论。
- 文档内嵌画板块。
- AI 生成画板。
- Mermaid / PlantUML 导入。
- SVG / PDF / PNG 导出。
- 模板市场。
- 小地图。
- 泳道、UML、时序图等专业图形库。

## 5. 当前 CloudDoc 实现差距

### 5.1 已具备

- 独立 `board` 文档类型。
- `/docs/{id}` 类型分流进入画板页。
- 新建画板入口。
- 基础节点：文本、矩形、圆角矩形、圆形、菱形。
- 基础连接线。
- 节点移动。
- 平移、缩放。
- 颜色属性面板。
- 自动保存和手动保存。
- 只读模式限制修改。

### 5.2 需要修正

- 当前顶部栏仍偏“独立应用页”，需要更接近飞书轻量顶栏。
- 当前工具栏按钮显示文字，不符合飞书图标工具栏样式。
- 当前没有图形库浮层，图形工具都直接平铺在工具栏上。
- 当前选中对象时使用右侧属性浮层，飞书视频中主要是对象附近的浮动工具条。
- 当前连接线只能点击两个节点生成中心点连线，不是从锚点拖拽吸附。
- 当前连接线缺少直线/折线、箭头端点、线条样式菜单。
- 当前对象没有缩放控制点。
- 当前文本编辑使用 `prompt`，不符合对象内直接编辑体验。
- 当前不支持复制、剪切、粘贴、创建副本、层级移动。
- 当前颜色面板太弱，需要紧凑色板。
- 当前画布背景是线性网格，需改成飞书式点阵。
- 当前图形类型不足，需补圆柱、三角形、星形、箭头、括号等基础图形。

## 6. 改进目标

### 6.1 产品目标

将 CloudDoc 基础画板从“可保存的 SVG 原型”提升为“接近飞书基础画板的可用流程图编辑器”。

### 6.2 体验目标

- 用户打开画板后第一眼感觉是专业画板工具，而不是普通文档页。
- 主要操作不离开画布完成，选中对象后就地编辑样式。
- 连接线创建方式符合流程图使用习惯。
- 文本和颜色编辑不打断用户，不使用浏览器 prompt。

## 7. 需求范围

### 7.1 页面布局改造

- 顶部栏压缩到 44px 左右。
- 左侧固定垂直工具栏图标化。
- 画布铺满主区域，使用点阵背景。
- 右下角保留缩放控件。
- 右侧属性面板改为可选辅助，不作为首要样式入口。

### 7.2 工具栏改造

工具栏分组：

- 选择。
- 形状。
- 文本。
- 便签或注释占位。
- 连接线。
- 框架/容器。
- 表格占位。
- 画笔占位。
- 更多。
- 评论占位。

V1 实现：

- 选择、形状、文本、连接线、更多。
- 其他工具先显示禁用或不显示，避免误导。

### 7.3 图形库

点击形状工具显示图形库浮层：

- 第一行：矩形、圆形、菱形、圆角矩形。
- 第二行：圆柱、箭头、平行四边形、六边形。
- 第三行：三角形、星形、左右箭头、加号。
- 底部：“更多图形”占位。

创建规则：

- 选择图形后进入放置模式。
- 在画布点击创建。
- 创建后自动选中新对象，并显示浮动工具条。

### 7.4 对象选中与调整

- 单击选中对象。
- 选中对象显示 8 个缩放控制点。
- 拖拽边角可调整大小。
- 拖拽对象主体可移动。
- 拖拽时显示轻量辅助线或坐标吸附占位。
- 点击空白取消选中。

### 7.5 对象内文本编辑

- 双击对象进入文字编辑。
- 文本编辑器覆盖在对象内部，不使用 `prompt`。
- 支持多行输入、自动换行。
- 失焦或按 `Esc` 退出编辑。
- `Enter` 在对象内换行，不创建新画板对象。

### 7.6 就地浮动工具条

选中形状对象时显示：

- 形状类型。
- 填充色。
- 边框色。
- 文字颜色。
- 字号。
- 对齐。
- 评论占位。
- 更多。

选中连接线时显示：

- 线型。
- 起点箭头。
- 终点箭头。
- 线条颜色。
- 线宽。
- 文字标签占位。
- 更多。

定位规则：

- 默认显示在对象下方 8px。
- 如果超出窗口底部，显示到对象上方。
- 如果超出窗口右侧，向左偏移。
- 点击画布空白或选择其他对象时切换或关闭。

### 7.7 连接线改造

- 图形对象四边中点显示连接锚点。
- 鼠标悬浮或选中对象时锚点可见。
- 从锚点拖出连接线。
- 拖到另一个对象锚点时吸附并创建连接。
- 连接线至少支持直线和正交折线。
- 连接线终点默认箭头。
- 拖动对象后连接线跟随锚点。

### 7.8 颜色和线条菜单

颜色菜单：

- 支持填充色、边框色、文字颜色。
- 常用色板不少于 24 个颜色。
- 支持透明或无填充。

线条菜单：

- 支持实线、虚线。
- 支持 1px、2px、4px 线宽。
- 支持无箭头、终点箭头、双向箭头。

### 7.9 更多菜单

对象更多菜单：

- 复制。
- 剪切。
- 粘贴。
- 创建副本。
- 删除。
- 上移一层。
- 下移一层。
- 置于顶层。
- 置于底层。

删除对象不需要确认，但必须可撤销。

### 7.10 快捷键

- `Delete` / `Backspace`：删除选中对象。
- `Cmd/Ctrl + C`：复制。
- `Cmd/Ctrl + X`：剪切。
- `Cmd/Ctrl + V`：粘贴。
- `Cmd/Ctrl + D`：创建副本。
- `Cmd/Ctrl + Z`：撤销。
- `Cmd/Ctrl + Shift + Z`：重做。
- `Esc`：退出文本编辑或关闭浮层。

## 8. 数据模型调整

当前 `content_json` 可继续承载画板数据，但需要补充字段：

```json
{
  "type": "board",
  "version": 2,
  "viewport": { "x": 0, "y": 0, "zoom": 1 },
  "nodes": [
    {
      "id": "node_1",
      "type": "rectangle",
      "x": 120,
      "y": 100,
      "width": 160,
      "height": 64,
      "text": "测试文本",
      "style": {
        "fill": "#e8f0ff",
        "stroke": "#5b7fd8",
        "strokeWidth": 1,
        "strokeDasharray": "",
        "fontSize": 14,
        "fontWeight": 400,
        "color": "#1f2937",
        "textAlign": "center",
        "verticalAlign": "middle"
      },
      "zIndex": 1
    }
  ],
  "connectors": [
    {
      "id": "connector_1",
      "from": { "nodeId": "node_1", "anchor": "right" },
      "to": { "nodeId": "node_2", "anchor": "left" },
      "routing": "orthogonal",
      "label": "",
      "style": {
        "stroke": "#8b95a5",
        "strokeWidth": 1.5,
        "strokeDasharray": "",
        "startArrow": "none",
        "endArrow": "arrow"
      },
      "zIndex": 0
    }
  ]
}
```

兼容规则：

- 旧版 `from: string, to: string` 连接线读取时自动转换为中心点连接。
- 后端校验需要允许 `version = 1` 和 `version = 2`，但保存时前端逐步写 `version = 2`。

## 13. 风险与注意事项

- 连接线锚点和折线路由会影响后续协作和导出能力，数据模型必须提前支持 anchor。
- 对象内文本编辑不应破坏键盘快捷键，需要区分 text editing mode 和 canvas mode。
- 浮动工具条和菜单要统一关闭逻辑，避免旧问题：失焦后残留、点击其他位置不消失。
- `next build` 与本地 dev server 共用 `.next`，测试后如需恢复 3100，需要清理 `.next` 并重启 dev server。
- 自动保存必须避免拖拽过程中高频写后端，推荐拖拽结束后立即标记 dirty，并用 800-1200ms debounce 保存。
