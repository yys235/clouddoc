# 画板 Image Node 图片形状设计

## 1. 背景和目标

普通画板形状已恢复为只支持文本。现在新增一种专门承载图片的画板节点，满足“粘贴图片后在画板中以独立图片元素显示”的需求，同时避免再次把普通文本形状变成图文混排容器。

目标：

- 新增 `type: "image"` 的图片节点。
- 在画板非文本编辑状态下粘贴图片时，上传图片并在鼠标附近创建图片节点。
- 图片节点支持选中、拖动、缩放、复制粘贴、删除、层级、对齐等现有节点能力。
- 图片节点提供专属工具栏能力，包括替换、预览、旋转、适应/填充显示、边框、透明度、复制、删除。
- 普通形状继续只支持 `text`，不恢复 `node.image` 或 `node.content` 图文混排能力。

非目标：

- 不做普通形状内图文混排。
- 不做图片节点内部文字编辑。
- 不做图片裁剪编辑器的复杂交互。第一版只提供显示模式和旋转。
- 不覆盖系统文本剪贴板；文本编辑、表格单元格编辑继续保留原复制粘贴行为。

## 2. 数据模型

在 `BoardNodeType` 中新增：

```ts
type BoardNodeType = ... | "image";
```

在 `BoardNode` 中新增专属图片字段：

```ts
type BoardImageFit = "contain" | "cover";

type BoardNode = {
  type: BoardNodeType;
  text: string;
  imageAsset?: {
    src: string;
    name?: string;
    mimeType?: string;
    width?: number;
    height?: number;
    size?: number;
  };
  imageFit?: BoardImageFit;
  imageRotation?: number;
  imageOpacity?: number;
};
```

约束：

- `imageAsset` 只对 `type: "image"` 生效。
- 普通文本形状即使历史数据带有 `imageAsset`，渲染和编辑也忽略。
- `text` 在图片节点中保留为空字符串，用于兼容现有节点复制、搜索摘要、plain text 生成逻辑。
- `imageRotation` 表示文档中永久生效的旋转角度，只允许 `0/90/180/270`。
- `imageFit` 默认 `contain`，避免粘贴大图时被裁掉。
- 图片节点保存仍使用画板 `version: 2`，因为这是新增节点类型，不是恢复富内容块模型。

## 3. 创建和粘贴交互

### 3.1 粘贴图片

触发条件：

- 当前焦点在画板根容器。
- 没有正在编辑普通形状文本。
- 没有正在编辑表格单元格。
- Clipboard 中存在图片文件或 image blob。

行为：

- 阻止浏览器默认粘贴。
- 调用现有 `uploadImageAsset(file)` 上传图片。
- 创建 `type: "image"` 节点，位置优先使用最近鼠标在画板中的坐标；如果没有鼠标坐标，则放在当前视口中心。
- 节点初始尺寸按图片自然宽高等比计算，最长边限制在 360px，最短边不低于 80px。
- 创建后自动选中新图片节点。

失败处理：

- 上传失败时显示非阻塞错误提示，不创建节点。
- 不支持的图片格式复用上传接口错误。

### 3.2 工具栏创建

形状面板中增加“图片”入口：

- 点击后打开文件选择。
- 选择图片后上传并在当前视口中心创建图片节点。
- 不把图片作为普通形状的内容插入。

## 4. 渲染和编辑

图片节点渲染：

- 使用节点矩形作为图片边界。
- `contain`：完整显示图片，可能留白。
- `cover`：填满节点，可能裁切边缘。
- 旋转按节点中心旋转。
- 透明度作用于图片本身。
- 边框、阴影、圆角使用现有节点样式能力。

选中态：

- 继续使用现有节点选中框和缩放手柄。
- 缩放默认保持图片比例。
- 按住 Shift 时允许自由缩放。
- 图片节点不可双击进入文本编辑。双击打开图片预览。

预览：

- 双击图片节点或点击工具栏“预览”打开遮罩。
- 预览支持放大、缩小、旋转、关闭。
- 预览中的旋转只影响预览态，不修改 `imageRotation`。
- 点击遮罩空白、Esc、关闭按钮都可退出预览。
- 预览打开后锁定背后画板滚动。

## 5. 图片节点工具栏

图片节点选中时使用图片专属工具栏，避免显示文字字号、加粗、对齐等无意义按钮。

第一版工具栏：

- 替换：选择新图片并更新 `imageAsset`，保留节点尺寸、位置、边框和旋转。
- 预览：打开图片预览遮罩。
- 旋转：每次顺时针 90 度，写入 `imageRotation`，永久生效。
- 适应/填充：在 `contain` 和 `cover` 之间切换。
- 边框：复用现有边框色、线宽入口。
- 透明度：复用或新增图片透明度入口。
- 复制：复用节点复制。
- 删除：复用节点删除。
- 更多：上移、下移、置顶、置底、锁定后续可扩展。

普通文本形状工具栏保持不变。

## 6. 复制粘贴和保存

内部画板复制：

- 选中图片节点时，`Cmd/Ctrl+C` 写入画板内部剪贴板。
- `Cmd/Ctrl+V` 复制图片节点，沿用同一个 `imageAsset.src`，不重复上传文件。
- 多选复制粘贴时图片节点和普通节点一起复制；连接线规则保持现有逻辑。

系统图片粘贴：

- 如果 Clipboard 中有图片文件，则创建新图片节点。
- 如果当前在文本输入、普通形状文字编辑、表格单元格编辑中，不拦截系统粘贴。

保存：

- 图片节点数据保存在 board `contentJson.nodes[]`。
- 后端资源引用扫描需要识别 `nodes[*].imageAsset.src`，确保文档版本和删除回收逻辑能保护图片文件。

## 7. 对现有功能影响

普通形状：

- 不新增 `node.image` 或 `node.content`。
- 普通形状粘贴图片不会把图片放进形状内部。

表格形状：

- 表格单元格粘贴保持现状。
- 图片节点不复用表格编辑态。

连线：

- 图片节点作为普通节点参与连线锚点计算。
- 不新增图片内部锚点。

只读和分享：

- 图片节点在只读和分享链接中可查看、可预览。
- 不显示编辑工具栏。

资源回收：

- 删除图片节点后，当前版本不再引用图片。
- 旧版本和软删除保留窗口内仍保护图片。
- 过期且无引用后由现有资源回收逻辑删除。

## 8. 测试计划

前端：

- `npm run build`
- 粘贴图片创建图片节点。
- 图片节点选中后显示图片专属工具栏，不显示文字工具。
- 替换、旋转、适应/填充、预览、删除可用。
- 图片节点复制粘贴后自动选中新副本。
- 普通文本编辑和表格单元格编辑中的粘贴行为不受影响。

后端：

- 增加资源引用测试：`nodes[*].imageAsset.src` 能被收集。
- 增加回收测试：图片节点删除后，当前版本引用消失；历史保护期后可被清理。

集成：

- 新建画板粘贴图片后保存，刷新页面图片仍显示。
- 分享/只读页面图片显示和预览正常。

## 9. 实施顺序

1. 扩展前端类型和 normalize 逻辑，新增 `image` 节点类型。
2. 增加图片节点渲染、双击预览和图片专属工具栏。
3. 接入 Clipboard 图片粘贴和形状面板图片上传。
4. 调整复制粘贴和缩放行为，确保图片节点保持比例。
5. 扩展后端资源引用扫描和测试。
6. 跑构建、测试并恢复 3100/8000 服务。
