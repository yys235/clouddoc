# 画板 Code Node 代码块形状设计

## 1. 背景和目标

画板普通图形当前定位为纯文本形状，图片已通过独立 Image Node 承载。代码块也应采用同样的独立节点模型，避免把普通图形重新扩展成复杂富内容容器。

目标：

- 新增 `type: "code"` 的画板代码节点。
- 代码节点专门承载多行代码，支持语言选择、自动换行、复制、折叠、内部滚动和高度调整。
- 普通图形继续只支持 `text`，不引入 `content` 富内容模型。
- 代码节点可参与画板现有能力：选中、拖动、缩放、多选、复制粘贴、删除、层级和连线。
- 只读和分享页面可查看、滚动、复制代码。

非目标：

- 不在普通矩形、圆形等图形内部嵌入代码块。
- 不实现富文本式“文字 + 代码 + 图片”混排。
- 不做完整 IDE 能力，例如语法高亮编辑、自动补全、格式化、运行代码。
- 不改变云文档正文代码块的数据模型，只复用其语言列表和交互经验。

## 2. 推荐方案

新增独立 Code Node：

```ts
type BoardNodeType = ... | "code";

type BoardNode = {
  type: BoardNodeType;
  text: string;
  codeLanguage?: string;
  codeWrap?: boolean;
  codeCollapsed?: boolean;
  codeHeight?: number;
};
```

字段语义：

- `text`：代码内容，保留换行和缩进。
- `codeLanguage`：代码语言，使用云文档代码块同一套语言值，默认 `plain_text`。
- `codeWrap`：是否自动换行，默认 `true`。
- `codeCollapsed`：是否折叠，默认 `false`。
- `codeHeight`：代码内容区高度，默认 `240`，限制在安全范围内。

设计约束：

- 这些 code 字段只对 `type: "code"` 生效。
- 普通图形即使历史数据带有 code 字段也忽略。
- 画板内容版本继续使用当前 board `version: 2`，因为这是新增节点类型，不恢复富内容块模型。

## 3. 创建入口

第一版创建入口：

- 形状面板新增“代码块”。
- 点击后在当前视口中心创建代码节点。
- 默认文本为空，双击后进入编辑态。

后续可扩展入口：

- 选中普通文本节点时提供“转换为代码块”。
- 在画板空白处粘贴多行文本时，识别为代码并创建代码节点。

第一版不自动把多行文本粘贴成代码节点，避免误判用户只是想创建普通多行文本。

## 4. 显示和编辑

### 4.1 非编辑态显示

代码节点由 header 和内容区组成：

- Header 显示“代码块”、语言、自动换行状态、复制按钮。
- 内容区使用等宽字体。
- 显示行号。
- 内容超出时在代码节点内部滚动，不撑开节点，不遮挡其他画板元素。
- `codeCollapsed=true` 时只显示 header 和一行摘要。

### 4.2 编辑态

进入方式：

- 双击代码节点进入代码编辑态。
- 选中代码节点后按 Enter 可进入编辑态。

编辑行为：

- 使用 textarea 保存原始代码文本。
- Enter 保留换行。
- Tab 插入两个空格或缩进选中行，不切换焦点。
- Shift+Tab 反向缩进选中行。
- Esc 提交并退出编辑态。
- 点击画布空白提交并退出编辑态。
- Cmd/Ctrl+A 在代码编辑态优先选中 textarea 内容；非编辑态选中节点。

复制粘贴：

- 编辑态内复制/粘贴走系统文本剪贴板。
- 非编辑态选中代码节点时，Cmd/Ctrl+C 走画板内部节点复制。
- 工具栏“复制代码”只复制 `text` 到系统剪贴板，不影响画板内部剪贴板。

## 5. 工具栏设计

代码节点选中时展示代码专属工具栏，避免显示无意义的普通文字样式按钮。

第一版工具栏：

- 语言：下拉选择主流语言和数据结构，复用云文档代码块语言列表。
- 自动换行：切换 `codeWrap`。
- 复制代码：复制 `text` 到系统剪贴板。
- 折叠/展开：切换 `codeCollapsed`。
- 边框/填充：复用节点样式入口。
- 更多：复制节点、删除、上移、下移、置顶、置底。

不显示：

- 字号。
- 加粗、斜体、下划线。
- 文本对齐。
- 垂直对齐。

这些操作对代码节点无明确意义，隐藏能减少误操作。

## 6. 尺寸、滚动和连线

尺寸：

- 初始宽度 520，高度 280。
- 最小宽度 240，最小高度 120。
- 可通过现有节点缩放手柄调整宽高。
- 内容区高度由节点高度扣除 header 后计算，不再单独撑开节点。

滚动：

- 代码内容区内部滚动。
- 鼠标位于代码内容区时，滚轮优先滚动代码内容；滚到边界后不穿透滚动画板。
- 非代码内容区滚轮保持画板现有缩放/滚动行为。

连线：

- 代码节点作为普通节点参与连线。
- 使用节点矩形边界计算锚点。
- 不提供代码行级别锚点。

## 7. 保存和兼容

保存：

- 代码节点数据保存在 board `contentJson.nodes[]`。
- `text` 参与 plain text 提取和搜索。
- 不新增后端表和资源引用记录，因为代码内容不是外部资源。

兼容：

- 旧画板不受影响。
- 未识别的 code 字段只在 `type: "code"` 时使用。
- 如果历史节点 `type` 不在允许列表中，继续按现有 normalize 逻辑过滤。

只读和分享：

- 显示代码节点。
- 可滚动查看。
- 可复制代码。
- 不可编辑语言、换行、折叠状态。

## 8. 与现有云文档代码块的关系

复用：

- 语言枚举和语言标签。
- 自动换行、复制、折叠、高度控制的交互语义。
- 主流语言和数据结构支持范围。

不复用：

- 不直接嵌入云文档 `CodeBlockSurface` 组件。画板节点处在 SVG/绝对定位/拖拽环境中，直接复用会增加事件冲突。
- 不复用云文档块级新增/删除逻辑。

可提取：

- 可把语言列表和 `sanitizeCodeLanguage` 提取到共享 util，避免画板和文档维护两套语言表。

## 9. 对现有功能影响

普通图形：

- 保持纯文本。
- 不新增图形内代码块。

图片节点：

- 不受影响。
- 图片节点和代码节点均为专用节点类型。

表格节点：

- 表格单元格编辑和粘贴保持现状。

多选复制：

- 代码节点作为普通节点复制。
- 多选中包含连接线时，仍按现有规则只复制两端节点都在复制范围内的连接线。

撤销/重做：

- 创建、删除、尺寸变化、语言变化、换行变化、折叠变化、代码编辑提交都进入现有 board history。
- 编辑态每次输入不逐字写 history，只在提交时写一次。

## 10. 测试计划

前端构建：

- `apps/web npm run build`

交互测试：

- 从形状面板创建代码节点。
- 双击进入编辑态并输入多行代码。
- Enter 保留换行。
- Tab 增加缩进，Shift+Tab 减少缩进。
- 点击画布空白提交退出。
- Esc 提交退出。
- 内容超出时只在代码节点内部滚动。
- 切换语言、自动换行、折叠。
- 复制代码到系统剪贴板。
- 复制粘贴整个代码节点后自动选中新节点。
- 多选复制代码节点和普通节点。
- 连线可连接到代码节点。

回归测试：

- 普通文本形状双击编辑不受影响。
- 表格单元格粘贴不受影响。
- 图片节点显示和工具栏不受影响。
- 只读/分享页面可显示和复制代码。

## 11. 实施顺序

1. 抽取或复用代码语言枚举和 sanitizer。
2. 扩展 `BoardNodeType`、`BoardNode` 和 normalize 逻辑。
3. 新增代码节点创建入口和默认节点工厂。
4. 新增代码节点渲染组件和编辑态 textarea。
5. 新增代码节点专属工具栏。
6. 接入代码节点复制、折叠、换行、语言、尺寸和 history。
7. 跑构建和关键回归测试。
8. 更新进度文档并恢复前后端服务。
